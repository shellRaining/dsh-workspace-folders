# 工作区文件夹

在 DeepSeek Harness 侧栏的工作区里新建文件夹，把这个工作区的会话分组收纳。文件夹只改变侧栏的显示方式，不动会话的工作目录、历史记录和所属工作区，也不会在磁盘上创建目录。

本插件是官方工作区列表 `@deepseek-ai/dsh-client-ui-workspace` 的 fork。安装后它停用官方列表，在同一位置换上自己，侧栏仍然只有一个列表。没有建文件夹时，外观和行为与官方列表一致。

## 功能

- 工作区菜单里的“新建文件夹”，以及会话菜单里的“移动到文件夹 ▸ 新建文件夹…”（一步完成新建和移入）。
- 会话菜单的“移动到文件夹”列出同一工作区的文件夹，在文件夹里时另有“移出文件夹”。
- 把会话拖到文件夹行上移入，拖到所属工作区行上移出；拖到两行之间时按落点移入或移出，并像官方拖动排序一样切换到“手动排序”。
- 文件夹菜单里的“新建会话”直接在文件夹里开新会话，发出第一条消息后归入该文件夹；没发消息就离开时，空白会话不归入。
- 文件夹可以折叠，折叠状态记在当前浏览器；文件夹菜单提供重命名和删除，删除时里面的会话回到文件夹外。
- “按工作区”和“按工作区树”显示文件夹；“单列表”和搜索结果保持官方的平铺方式。

只有一层文件夹，“未分组”下不能建文件夹，会话不能拖到其他工作区。

## 安装

```sh
dsh plugin --profile <profile> add @shellraining/dsh-workspace-folders
```

也可以在 **插件** > **添加插件** 里安装。安装、升级或卸载后，重启 DSH 再刷新页面。

## 版本对应

本插件和侧栏、会话等宿主包按版本耦合，每个版本只声明一个 DSH 版本（`engines.dsh`）。DSH 版本不匹配时，DSH 会跳过本插件，侧栏回到官方列表，文件夹数据保留，升级到对应版本后恢复。

| --- | --- |

## 数据

文件夹列表和会话归属存在宿主端的 `~/.dsh/storages/workspace_folders.json`，同一 DSH 的桌面端和浏览器共用一份。文件夹按工作区目录记录，从列表移除工作区再重新添加同一目录，文件夹和归属都会恢复。卸载本插件不删除这份数据。

多个窗口之间不实时同步，在一个窗口里改了文件夹，其他窗口刷新后看到最新结果。
